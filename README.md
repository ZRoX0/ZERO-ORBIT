# ZERO-ORBIT

### Autonomous Web Attack-Surface & Resilience Analyzer

> **Map. Test. Repair. Verify.**

أداة Cybersecurity مكتوبة بأربع لغات (Python / Go / C++ / Rust) لفحص المواقع التي تملكها أو لديك تصريح رسمي باختبارها. تبني خريطة لسطح الهجوم، تكتشف نقاط الضعف وسوء الإعدادات، تختبر التحمل بشكل آمن، وتُنتج تقارير مفصّلة.

---

## ⚠️ تنبيه قانوني وأخلاقي — اقرأ أولاً

**ZERO-ORBIT مخصّصة فقط للأنظمة التي تملكها أو لديك تصريح موقّع باختبارها.**

- ❌ ممنوع استخدامها ضد أي نظام بدون تصريح كتابي.
- ❌ لا تحتوي على: Credential Theft / Password Dumping / Malware / Persistence / Stealth.
- ✅ تحتوي على: Scope Enforcement / Safe Verification / Rate Limiting / Hard Caps.
- ✅ الأداة **default-deny**: لن ترسل أي طلب لأي هدف غير مسجَّل في `config/scope.txt`.

المستخدم هو المسؤول القانوني الوحيد عن أي استخدام. المطوّر غير مسؤول عن أي إساءة.
